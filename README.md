# 🌬️ Wind Tunnel Designer

Um simulador de túnel de vento 2D onde você pode desenhar um objeto
e observar visualmente o fluxo de ar ao redor dele.

## 🚀 Demonstração

Desenhe uma forma dentro do túnel e clique em:

▶ Iniciar túnel

As partículas representam o fluxo de ar.

## ✨ Recursos

- ✏️ Desenho livre com mouse ou touch
- 🌬️ Simulação de fluxo de ar
- 🎚️ Controle de velocidade do vento
- 🌪️ Controle de turbulência
- 💨 Controle da quantidade de partículas
- 🛩️ Exemplo de aerofólio
- 📊 Estimativa visual de arrasto
- 💾 Exportação do desenho em PNG
- 📱 Interface compatível com celular
